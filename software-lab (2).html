Keep this lab on GitHub

GitHub only hosts the page. Connect a repo so uploads are written into lab-data.json and still there next time — even on another computer.

  1. Turn on GitHub Pages for the repo (Settings → Pages → Deploy from branch).
  2. Create a token with Contents: Read and write at github.com/settings/tokens.
  3. Paste it below. The token stays in this browser only.
